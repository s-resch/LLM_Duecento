# Experimente zu lyrischen Texten des italienischen Duecento und Large Language Models (LLMs)

This repository contains code and material for the experiments regarding LLMs and texts from Italian Duecento presented in Sascha Resch's essay "Experimente zu lyrischen Texten des italienischen Duecento und Large Language Models (LLMs)", published in _xxx_. See there for a detailed description of textual corpus, results and methodic considerations.

# Roadmap

The results presented in this repository and in the corresponding essay are preliminary. Further steps/iterations inlcude:

- Extension of textual corpus
- Using LLMs as (qualitative) judges
- Experiments regarding further tasks (as described in Jannidis et al. 2025)
- Evaluation of basic NLP tasks (the project is being realized funded by the Early Career Program of the Faculty of Linguistics and Literary Studies at Ludwig Maximilian University of Munich)
